**Основа записи:** грузинский алфавит (мхедрули, 33 буквы) + диакритические знаки транслитерации (IPA). Каждое слово = одна фонема. Отсутствующие в грузинском фонемы — комбинации букв + знаки.


## 1. Фонология Toki Pona

Toki Pona — конструированный минималистичный язык Сони Лэнг (2001). Всего **14 фонем**:

- **9 согласных:** /p, t, k, s, m, n, l, j, w/
- **5 гласных:** /a, e, i, o, u/

Слоги: (C)V(N). Запрещены *wu, *wo, *ji, *ti, финальная -n перед m/n. Ударение — на первом слоге. То́нов и долготы нет.

## 4. Знак паузы

**0** (в виде математического нуля) — знак паузы между словами; вариант — **∅**.

Каждое слово = один символ; слова разделяются нулём-паузой:

```
toki pona li pona  →  ო 0 ბ 0 ა 0 ბ
jan li toki       →  ვ 0 ა 0 ო
```

Пробел можно опускать: `ო0ბ0ა0ბ`.

## 8. Примечания

- Топ-3 по частотности: **li→ა, mi→ი, e→ე** (по указанию пользователя). Далее — гласные (ო, უ), затем согласные IPA: пульмонические → клики → имплозивные → эйективные → палатализованные (ʲ) → лабиализованные (ʷ).
- Все обозначения визуально уникальны (проверено скриптом, коллизий нет). Группа უ: u→უ, y→უ̈, ʉ→უ̨, ɯ→უ̄, ʏ→უ̆, ʊ→უ̛, uː→უː, ũ→უ̃, ṳ→უ̤, ṵ→უ̰, тоны უ́ უ̀ უ̌ უ̂.
- Дополнительные знаки грузинской графики: **ჶ** (фи, /f/), **ჸ** (паири, /ʔ/), **ჲ** (hie, /j/).
- Порядок присвоения дифтонгов: пары гласных a,i,e,o,u,y,ɨ,ʉ,ɯ,ɪ,ʊ,ø,ə,ɛ,ɔ,æ,ɑ (272 комбинации, использовано 110).
- ~82 фонем инвентаря — резерв для имён собственных и будущих nimi ku lili.
