# აი (Ai) — the one-phoneme language

**აი** ([ai], *Ai*) is a constructed minimalist language in the spirit of Toki Pona — pushed to the extreme: **one word = one phoneme = one symbol**.

The whole vocabulary is **14 roots**. Meaning is built by direct composition. Written in Georgian script (Mkhedruli), words separated by the zero-sign **0**.

```
ი 0 ა 0 ლ 0 ბ 0 იე 0 ა 0 ვბ
I am. Know good. We are good humans.
```

## Why?

- **Minimalism as philosophy** — 14 signs to express the world.
- **Learn in minutes** — 14 roots, one grammar rule (SVO + concatenation).
- **Speak to essentials** — like Toki Pona, but even simpler.

## The 14 roots

| Symbol | Sound | Meaning | | Symbol | Sound | Meaning |
|:------:|:-----:|---------|---|:------:|:-----:|---------|
| ა | /a/ | exist, be | | ვ | /v/ | human, person |
| ი | /i/ | I, speaker | | ზ | /z/ | thing, matter |
| ე | /e/ | you, hearer | | თ | /t/ | time |
| ო | /o/ | speak, word | | კ | /k/ | place |
| უ | /u/ | this, that | | ლ | /l/ | know, mind |
| ბ | /b/ | good | | მ | /m/ | many, much |
| გ | /g/ | bad, evil | | დ | /d/ | not, absence |

## Grammar (one paragraph)

Word order **SVO**: `ი 0 ლ 0 ზ` — "I know a thing". Modifiers concatenate directly: `ვბ` = good human, `ლმ` = wisdom. Negation: `დ` before predicate: `ი 0 დ 0 ლ` — "I do not know". Question: predicate first + intonation: `ლ ე?` — "Do you know?". Imperative: predicate alone: `ორ!` — "Speak!". Pause between words — **0**; sentence end — **00**.

## Numbers

Diphthong signs: **Æ**=1, **Ꜷ**=2, **Ǣ**=3, **Œ**=4, **Ꝏ**=5, **Ꝏ̆**=6, **Ḭ**=7, **Ẹ**=8, **Ụ**=9, **ᵫ**=10, **Ī**=11, **Ų**=12… (272 one-symbol numerals).
