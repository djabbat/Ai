## Project
【აი】 (Ai) — constructed minimalist language **აი** (Ai, "one-phoneme language"). Inspired by Toki Pona; 14 roots, one phoneme per word, Georgian script (Mkhedruli), zero-sign 0 as pause. Public GitHub repository: djabbat/Ai (latinized: GitHub allows ASCII only).

## Language facts (quick)
- 14 phonemes: /p t k s m n l j w/ + /a e i o u/
- 14 roots: ა exist, ი I, ე you, ო speak, უ this, ბ good, გ bad, დ not, ვ human, ზ thing, თ time, კ place, ლ know, მ many
- Grammar: SVO; modifiers attach directly (ვბ = good human); negation დ before predicate; question = VS + intonation
- Numbers: diphthongs Æ=1, Ꜷ=2, Ǣ=3, Œ=4, Ꝏ=5…
