# აი — язык «одной фонемы»

**აი** (читается [ai] — «аи», лат. *Ai*) — конструированный минималистичный язык, созданный 2026-08-10 по образцу Toki Pona, но радикальнее: **каждое слово — одна фонема, один символ**.

Название — из двух первых гласных системы: **ა** (существование) + **ი** (я) = *«я есмь»* — бытие говорящего. Это и есть философия языка: существование, простота, здесь и сейчас.

---

## 1. Философия

- **14 корней** — как 14 фонем. Никаких лишних слов.
- **Один символ = одно слово = одна идея.** Смысл строится композицией (слитным соединением) символов, как в Toki Pona — но ещё проще.
- **Письменность:** грузинский алфавит (мхедрули). Пауза между словами — **0** (нулевой знак).
- Язык учится за минуты. Говорить на нём — значит думать о главном.

## 2. Фонология (14 фонем)

Как в Toki Pona: 9 согласных + 5 гласных. Запись — грузинская.

| Фонема | Груз. | Фонема | Груз. | Фонема | Груз. |
|:------:|:-----:|:------:|:-----:|:------:|:-----:|
| /a/ | **ა** | /p/ | **პ** | /n/ | **ნ** |
| /i/ | **ი** | /t/ | **ტ** | /l/ | **ლ** |
| /e/ | **ე** | /k/ | **კ** | /j/ | **ჲ** |
| /o/ | **ო** | /s/ | **ს** | /w/ | **უ̆** |
| /u/ | **უ** | /m/ | **მ** | | |

Слоги: (C)V(N). Ударение на первом слоге. Пауза между словами — знак **0**; конец предложения — **00**.

## 3. Словарь — 14 корней

Каждый корень — семантический примитив (осознанно не совпадает с присвоениями Toki Pona — это самостоятельный язык):

| Символ | Фонема | Значение | Примеры-композиции |
|:------:|:------:|----------|--------------------|
| **ა** | /a/ | существовать, быть, есть | კა — мир (место-бытия) |
| **ი** | /i/ | я, говорящий | იე — мы (я+ты) |
| **ე** | /e/ | ты, слушающий | ვე — ты-человек, собеседник |
| **ო** | /o/ | говорить, язык, слово | ომ — речь (много слов) |
| **უ** | /u/ | это, тот (указатель) | უზ — эта вещь |
| **ბ** | /b/ | хороший, добрый | ვბ — друг (хороший человек) |
| **გ** | /g/ | плохой, злой | ვგ — враг (плохой человек) |
| **დ** | /d/ | нет, не, отсутствие | დლ — незнание |
| **ვ** | /v/ | человек, лицо, существо | ვვ — люди (человек-человек) |
| **ზ** | /z/ | вещь, объект, материя | ზბ — дар (хорошая вещь) |
| **თ** | /t/ | время, момент | თბ — праздник (хорошее время) |
| **კ** | /k/ | место, пространство | კი — дом (моё место) |
| **ლ** | /l/ | знать, знание, сознание | ლმ — мудрость (много знания) |
| **მ** | /m/ | много, множество, очень | მზ — богатство (много вещей) |

## 4. Грамматика

Изолирующий язык, строгий порядок слов:

1. **Порядок SVO:** субъект → предикат → объект.
   - ი 0 ა — «я есть»
   - ვ 0 ო — «человек говорит»
   - ი 0 ლ 0 ზ — «я знаю вещь»
2. **Модификатор** присоединяется слитно после определяемого (как в sitelen pona): ვბ = добрый человек; ზმ = много вещей; ობ = доброе слово.
3. **Притяжательность** — слитно: ზი = моя вещь; კე = твоё место.
4. **Отрицание:** დ (нет) перед предикатом: ი 0 დ 0 ლ — «я не знаю»; დ 0 ა — «не существует».
5. **Вопрос:** предикат в начало (VS) + интонация; в письме — знак ? : ა ი? — «есть ли я?»; ლ ე? — «знаешь ли ты?»
6. **Повелительное:** предикат без субъекта: ო! — «говори!»; ლ! — «знай!»
7. **Связка «и»:** повтор субъекта или просто пауза 0 (как en в Toki Pona — слова просто рядом): ი 0 ე 0 ა — «я и ты существуем».

## 5. Числа

Числительные — **дифтонги** (односимвольные обозначения, в порядке таблицы дифтонгов): Æ=1, Ꜷ=2, Ǣ=3, Œ=4, Ꝏ=5, Ꝏ̆=6, Ḭ=7, Ẹ=8, Ụ=9, ᵫ=10, Ī=11, Ų=12… — всего 272 числа одной буквой.

Составные числа — композиция: Ꝏ 0 Æ — «пять ноль один» = 6? Нет: 0 — пауза, значит: ÆꜶ — «12» (слитно). Большие числа — через паузу: Ꝏ 0 Ų — «5 и 12» = 17.

## 6. Имена собственные и заимствования

- Имена людей и мест — дифтонги (как числа, но по смыслу): Джаба → **ჲჲ**? Нет: имя подбирается по звучанию дифтонга или лигатуры. Произвольное имя: **Æ** (Джаба), **Ꜷ** (Георгия) — краткие и красивые.
- Заимствования — описательные композиции: автомобиль = ზო (вещь-ездит? нет, ო = говорить)… описание: «быстрая вещь» = ზბმ? (хорошая-много вещь?). Словарь мал — описываем мир через 14 корней.

## 7. Примеры предложений

| აი | Перевод |
|----|---------|
| ი 0 ა | Я есть. |
| იე 0 ა | Мы есть (мы существуем). |
| ვბ 0 ო 0 ბ | Добрый человек говорит доброе. |
| ი 0 ლ 0 ზბ | Я знаю добрую вещь (мне хорошо). |
| დ 0 ა 0 გ | Не существует зла. |
| ლ ე 0 ზ? | Знаешь ли ты эту вещь? |
| ო 0 დ 0 ო | Молчи! (букв. «говори-не-говори») |
| კი 0 ა 0 კბ | Мой дом — хорошее место. |
| თბ 0 იე 0 ო | В праздник мы говорим. |
| ი 0 ლ 0 ა | Я знаю, что существую (я осознаю бытие). |

**Текст-манифест языка:**
```
ი 0 ა 0 ლ 0 ბ 0 იე 0 ა 0 ვბ
Я есмь. Знай добро. Мы — добрые люди.
```

## 8. Сравнение с Toki Pona

| | Toki Pona | აი |
|---|---|---|
| Слов в словаре | ~120–140 | **14** |
| Фонем | 14 | 14 |
| Символ на слово | 1–3 буквы | **1** |
| Грамматика | частицы li, e, la, pi | позиция (SVO) + слитная композиция |
| Разделитель слов | пробел | **0** (нулевой знак) |
| Числа | wan, tu, luka, mute, ale | дифтонги Æ Ꜷ Ǣ Œ Ꝏ… |

*აი — язык одной буквы: весь мир в 14 знаках.*
