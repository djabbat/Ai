# აი (Ai) — Language Specification

**Version:** 1.0 | **Date:** 2026-08-10
**Author:** Jaba Tqemaladze

**აი** ([ai], *Ai*) — a constructed minimalist language modeled on Toki Pona, pushed to the extreme: **one word = one phoneme = one symbol**.

The name comes from the first two vowels: **ა** (to exist) + **ი** (I) = *"I am"* — the being of the speaker. That is the philosophy: existence, simplicity, here and now.

---

## 1. Philosophy

- **14 roots** — like the 14 phonemes. No extra words.
- **One symbol = one word = one idea.** Meaning is built by composition (direct concatenation), as in Toki Pona — but even simpler.
- **Script:** Georgian alphabet (Mkhedruli). Pause between words — **0** (zero-sign).
- Learnable in minutes. Speaking it means thinking about what matters.

## 2. Phonology (14 phonemes)

As in Toki Pona: 9 consonants + 5 vowels. Georgian script.

Syllables: (C)V(N). Stress on first syllable. Pause between words — **0**; sentence end — **00**.

## 4. Grammar

Isolating language, strict word order:

1. **SVO:** subject → predicate → object.
   - ი 0 ა — "I am"
   - ვ 0 ო — "a human speaks"
   - ი 0 ლ 0 ზ — "I know a thing"
2. **Modifier** concatenates directly after the head (as in sitelen pona): ვბ = good human; ზმ = many things; ობ = a good word.
3. **Possessive** — concatenated: ზი = my thing; კე = your place.
4. **Negation:** დ (not) before the predicate: ი 0 დ 0 ლ — "I do not know"; დ 0 ა — "does not exist".
5. **Question:** predicate first (VS) + intonation; written with ?: ა ი? — "am I?"; ლ ე? — "do you know?"
6. **Imperative:** predicate alone: ორ! — "speak!"; ლ! — "know!"
7. **"And"** — simple juxtaposition (like en in Toki Pona): ი 0 ე 0 ა — "I and you exist".

## 5. Numbers

Numerals are **diphthongs** (one-symbol signs, in table order): Æ=1, Ꜷ=2, Ǣ=3, Œ=4, Ꝏ=5, Ꝏ̆=6, Ḭ=7, Ẹ=8, Ụ=9, ᵫ=10, Ī=11, Ų=12… — 272 one-symbol numerals.

Compound numbers — concatenation: ÆꜶ = 12. Larger numbers via pause: Ꝏ 0 Ų = 5 + 12 = 17.

## 6. Proper names and loanwords

- Personal/place names — diphthongs (chosen by sound or meaning of the sign).
- Loanwords — descriptive compositions of the 14 roots.

ი 0 ა 0 ლ 0 ბ 0 იე 0 ა 0 ვბ

## 8. Comparison with Toki Pona

| | Toki Pona | აი |
|---|---|---|
| Dictionary size | ~120–140 words | **14** |
| Phonemes | 14 | 14 |
| Symbols per word | 1–3 letters | **1** |
| Grammar | particles li, e, la, pi | position (SVO) + concatenation |
| Word separator | space | **0** (zero-sign) |
| Numerals | wan, tu, luka, mute, ale | diphthongs Æ Ꜷ Ǣ Œ Ꝏ… |

*აი — the language of one letter: the whole world in 14 signs.*
