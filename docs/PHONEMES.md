## 2. Georgian script as phoneme writing

Mkhedruli (33 letters) covers most common phonemes; missing ones are combinations + transliteration diacritics (IPA).

> Georgian კ პ ტ წ ჭ ყ are ejective; თ ფ ქ aspirated. For plain /p t k/ of აი we use პ ტ კ; aspirated /pʰ tʰ kʰ/ → ფ თ ქ.

Additional Georgian-graphic signs: **ჶ** (phi, for /f/), **ჸ** (pairi, for /ʔ/), **ჲ** (hie, for /j/).

## 3. Zero-sign — pause

**0** (mathematical zero) — pause between words; alternative **∅**. Sentence end: **00**.

```
toki pona li pona  →  ო 0 ბ 0 ა 0 ბ   (demo on Toki Pona mapping)
jan li toki       →  ვ 0 ა 0 ო
```

## 4. Diphthongs — one-symbol signs

Common world diphthongs get single symbols intuitively resembling letters of the source alphabets (ligatures A+E→Æ, A+U→Ꜷ, O+E→Œ, O+O→Ꝏ, E+U→ᵫ; Cyrillic iotated Я Ё Ю Є Ї; labial → Ԝ).

| Diphthong | Examples | Georgian | Sign | Logic |
|:---------:|----------|:--------:|:----:|-------|
| /aɪ/ | EN *my*, DE *mein* | აი | **Æ** | ligature A+E |
| /aʊ/ | EN *house*, DE *Haus* | აუ | **Ꜷ** | ligature A+U |
| /eɪ/ | EN *day* | ეი | **Ǣ** | Æ with macron |
| /ɔɪ/ | EN *boy*, DE *neu* | ოი | **Œ** | ligature O+E |
| /oʊ/ | EN *go* | ოუ | **Ꝏ** | ligature O+O |
| /əʊ/ | UK *go* | ე̨უ | **Ꝏ̆** | Ꝏ + breve |
| /ɪə/ | UK *ear* | ი̆ა | **Ḭ** | I + dot below |
| /eə/ | UK *air* | ეა | **Ẹ** | E + dot below |
| /ʊə/ | UK *cure* | უ̛ა | **Ụ** | U + dot below |
| /eu/ | ES *deuda* | ეუ | **ᵫ** | ligature E+U |
| /ie/ | DE *Liebe* | იე | **Ī** | I + macron |

| /ja/ | RU *я* | ია | **Я** | Cyrillic |
| /je/ | UK *є* | იე | **Є** | Cyrillic |
| /jo/ | RU *ё* | იო | **Ё** | Cyrillic |

| /wa/ | EN, Dungan | უ̆ა | **Ԝ** | Cyrillic W |

Diacritic logic: ¯ macron = long/tense (Ǣ Ī); ˘ breve = short/neutral (Ꝏ̆); ̣ dot below = gliding to schwa (Ḭ Ẹ Ụ); ̨ ogonek = movement of second vowel (Ų).

## 5. Core: 155 signs = full standard IPA

The 155-sign core is exactly the standard IPA chart: 107 letters + 31 diacritics + 17 suprasegmentals = 155 (International Phonetic Association, 2018). 143 signs assigned to Toki Pona words; 12 reserve.

## 6. Extended inventory for აი

Beyond the 155-sign core: 225 one-symbol phonemes + 272 diphthongs (reserve for proper names and future loanwords). Collision-free (script-verified).
